# tSCPPut

Last updated: 9/30/2026

Copies files to the defined SCP server.

tSCPPut copies defined files to a
remote SCP server over a fully encrypted channel.

## tSCPPut Standard properties

These properties are used to configure tSCPPut running in the Standard Job framework.

The Standard
tSCPPut component belongs to the Internet family.

The component in this framework is available in all Talend
products.

## Basic settings

| Properties | Description |
| --- | --- |
| Host | SCP IP address. |
| Port | Listening port number of the SCP server. |
| Username | SCP user name. |
| Authentication method | SCP authentication method. |
| Password | SCP password.  To enter the password, click the [...] button next to the password field, enter the password in double quotes in the pop-up dialog box, and click OK to save the settings. |
| Remote directory | Path to the destination folder. |
| Filelist | File name or path to the file(s) to copy. |
