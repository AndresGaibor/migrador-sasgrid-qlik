# tCassandraClose

Last updated: 9/30/2026

Disconnects a connection to a Cassandra server so as to release occupied
resources.

This component is not shipped with your Talend Studio by
default. You need to install it using the Feature Manager. For more information, see [Installing features using the Feature Manager](/talend/r/en-US/8.0/studio-user-guide/install-features-to-talend-studio).

## tCassandraClose Standard properties

These properties are used to configure tCassandraClose running in the Standard Job framework.

The Standard
tCassandraClose component belongs to the Big Data and the Databases NoSQL families.

The component in this framework is available in all Talend products
with Big Data and in Talend Data Fabric.

## Basic settings

| Properties | Description |
| --- | --- |
| Component List | Select an active Cassandra connection to be closed. |
