# tWriteXMLFields

Last updated: 9/30/2026

Converts records into byte arrays.

tWriteXMLFields generates strings or byte arrays for output
components such as tKafkaOutput, which requires serialized data, and
tJMSOutput, which requires strings. It embeds incoming data in a
single XML column.
