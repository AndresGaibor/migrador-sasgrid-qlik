# cDirect

Last updated: 9/30/2026

Produces and consumes messages synchronously in different threads within a single
CamelContext.

For more information, see the Apache camel documentation <https://camel.apache.org/components/latest/>.

## cDirect Standard properties

These properties are used to configure cDirect running in the Standard Job framework.

The Standard
cDirect component belongs to the Core family.

## Basic settings

| Properties | Description |
| --- | --- |
| Name | This option appears when cDirect is used as a start component in a Route.  Type in any string that uniquely identifies the endpoint. |
| Use Exist cDirect | This option appears when cDirect is used as a middle or end component in a Route.  Click [...] and select the corresponding consumer in the dialog box. |

## Usage

| Usage guidance | Description |
| --- | --- |
| **Usage rule** | cDirect is used as a start, middle, or end component in a Route. |
| Limitation | n/a |
