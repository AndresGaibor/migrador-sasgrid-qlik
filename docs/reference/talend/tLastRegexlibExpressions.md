# tLastRegexlibExpressions

Last updated: 9/30/2026

Returns a dataset holding information about the N most recent regular expressions
added to the library and that match the query at <http://regexlib.com>.

This component is not shipped with your Talend Studio by
default. You need to install it using the Feature Manager. For more information, see [Installing features using the Feature Manager](/talend/r/en-US/8.0/studio-user-guide/install-features-to-talend-studio).

## tLastRegexlibExpressions Standard properties

These properties are used to configure tLastRegexlibExpressions running in the Standard Job framework.

The Standard
tLastRegexlibExpressions component belongs to the Data Quality family.

This component is available in Talend Data Management Platform, Talend Big Data Platform, Talend Real-Time Big Data Platform, Talend Data Services Platform and in
Talend Data Fabric.

## Basic settings

| Properties | Description |
| --- | --- |
| Schema and Edit schema | These fields are read-only. The output schema of this component contains the following fields: *Title, Expression, Description, Matches, Non-matches, Author, Rating*. |
| Max Rows | Enter the max number of the expressions you want to get. |
