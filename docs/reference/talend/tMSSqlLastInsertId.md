# tMSSqlLastInsertId

Last updated: 9/30/2026

Retrieves the last primary keys added by a user to a MSSql table.

tMSSqlLastInsertId displays the last
IDs added to a table from a MSSql specified connection.

## tMSSqlLastInsertId Standard properties

These properties are used to configure tMSSqlLastInsertId running in the Standard Job framework.

The Standard
tMSSqlLastInsertId component belongs to the Databases family.

The component in this framework is available in all Talend
products.

Information noteNote: This component is a specific version of a dynamic database
connector. The properties related to database settings vary depending on your database
type selection. For more information about dynamic database connectors, see [DB Generic components](/talend/r/en-US/8.0/components/db-generic/db-generic-component).

Information noteNote: When building a Job as an OSGI Bundle for ESB, MS SQL Server
drivers jtds and mssql-jdbc used by the SQL Server components are not included in the build
artifact. To run the artifact in Talend Runtime, you need
to deploy the drivers manually by copying the drivers to the
<TalendRuntimePath>/lib folder and restart Talend Runtime.
