# tSalesforceMarketingConnection

Last updated: 9/30/2026

Opens a connection to Salesforce Marketing Cloud.

This component is not shipped with your Talend Studio by
default. You need to install it using the Feature Manager. For more information, see [Installing features using the Feature Manager](/talend/r/en-US/8.0/studio-user-guide/install-features-to-talend-studio).

## tSalesforceMarketingConnection Standard properties

These properties are used to configure tSalesforceMarketingConnection
running in the Standard Job framework.

The Standard
tSalesforceMarketingConnection component belongs to the Business and the Cloud families.

The component in this framework is available in all Talend
products.

## Basic settings

| Properties | Description |
| --- | --- |
| Property Type | Select the way the connection details will be set.   * Built-In: The connection details will be set   locally for this component. You need to specify the values for all   related connection properties manually. * Repository: The connection details stored   centrally in Repository > Metadata will be reused by this component.  You need to click   the [...] button next to it and in the pop-up   Repository Content dialog box, select the   connection details to be reused, and all related connection   properties will be automatically filled in. |
| Subdomain | Enter your subdomain. It can be found on the Setup > Installed Packages page of your Salesforce account in the authentication base URI, with this format: `https://<subdomain>.auth.marketingcloudapis.com` |
| Auth mode | Select the authentication mode from the drop-down list:  * Access token: Select this option if you are using a   client ID and client secret to authenticate the Salesforce Marketing Cloud   API. * Username token: * Select this option if you are using a username and a password to   authenticate the Salesforce Marketing Cloud API. |
| Client ID and Client secret | Enter the client ID and client secret used to access Salesforce Marketing Cloud. It can be found on the Setup > Installed Packages page of your Salesforce account. |
| Username and Password | Enter the username and password used to access Salesforce Marketing Cloud. |
