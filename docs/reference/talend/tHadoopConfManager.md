# About Talend components for Jobs

Last updated: 9/30/2026

Use Talend components to build data integration Jobs. Each component is a functional piece that performs a single operation, such as extracting, filtering, or loading data for example.

[## *Install components with the Feature Manager*

Install and use components that are not installed by default in Talend Studio.](/talend/en-US/studio-user-guide/8.0/managing-features-in-talend-studio)

[## *Talend Studio components availability*

Browse component details and availability information to choose the right components for your Jobs.](/talend/en-US/studio-components-availability/8.0/)

[## *Supported versions of third-party systems*

Make sure that the system versions, database versions, or business applications versions you are using are compatible with Talend Studio components.](/talend/en-US/studio-user-guide/8.0/supported-third-party-system-database-business-application-versions)
