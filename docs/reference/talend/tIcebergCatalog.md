# tIcebergCatalog properties for Apache Spark Batch

Last updated: 9/30/2026

These properties are used to configure tIcebergCatalog running
in the Spark Batch Job framework.

The Spark Batch
tIcebergCatalog component belongs to the Big Data family.

The component in this framework is available in all Talend
products.

This component is available when you have installed the 8.0.1-R2024-04 Studio Monthly or a
later one provided by Talend. For
more information, check with your administrator.

## Basic settings

| Properties | Description |
| --- | --- |
| Register new catalog | Select this parameter to register a new catalog. |
| Replace default spark\_catalog with Iceberg's SparkSessionCatalog | Select this parameter to replace the default session Spark Catalog. For more information, see [Replacing the session catalog](https://iceberg.apache.org/docs/latest/spark-configuration/#replacing-the-session-catalog) from Iceberg documentation. |
| Name | Enter the name of the catalog. |
| Type | Select the type of catalog to be created from the drop-down list:  * Hadoop: creates an Iceberg catalog loading tables   from a Hadoop warehouse. * Hive: creates an Iceberg catalog loading tables from   a Hive metastore. * Rest: creates an Iceberg catalog loading table from   a REST metastore. * Custom: creates an Iceberg catalog loading tables   from a custom metastore. |
| Warehouse path | Enter the root path to the warehouse in which the catalog is stored. This parameter is only available when you select Hadoop from the Type drop-down list. |
| Uri | Enter the metastore URI string. This property is only available when you select Hive or Rest from the Type drop-down list. |
| Catalog implementation | Enter the custom catalog implementation to be used. This property is only available when you select Custom from the Type drop-down list. |
| Catalog properties | Enter any extra properties to be used for the catalog. For more information, see [Configuration](https://iceberg.apache.org/docs/latest/configuration/) from the Iceberg documentation. This property is only available when you select the Register new catalog parameter. |

## Global Variables

| Variables | Description |
| --- | --- |
| ERROR\_MESSAGE | The error message generated by the component when an error occurs. This is an After variable and it returns a string. |

## Usage

| Usage guidance | Description |
| --- | --- |
| Usage rule | This component is generally used with other Iceberg components. |

# tIcebergCatalog properties for Apache Spark Structured Streaming

Last updated: 9/30/2026

[Preview](https://help.qlik.com/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Introduction/feature-preview-program-overview.htm)

These properties are used to configure tIcebergCatalog running
in the Spark Structured Streaming Job framework.

The Spark Structured Streaming
tIcebergCatalog component belongs to the Databases family.

The streaming version of this component is available in Talend Real-Time Big Data Platform and in
Talend Data Fabric.

## Basic settings

| Properties | Description |
| --- | --- |
| Register new catalog | Select this check box to register a new catalog. |
| Replace default spark\_catalog with Iceberg's SparkSessionCatalog | Select this check box to replace the default Spark catalog. For more information, see [Replacing the session catalog](https://iceberg.apache.org/docs/latest/spark-configuration/#replacing-the-session-catalog) from Iceberg documentation. |
| Name | Enter the name of the catalog. |
| Type | Select the type of catalog from the drop-down list:  * Hadoop: creates an Iceberg catalog loading tables   from a Hadoop warehouse. * Hive: creates an Iceberg catalog loading tables from   a Hive metastore. * Rest: creates an Iceberg catalog loading tables from   a REST metastore. * Custom: creates an Iceberg catalog loading tables   from a custom metastore. |
| Warehouse path | Enter the root path to the warehouse in which the catalog is stored. This property is only available when you select Hadoop from the Type drop-down list. |
| Uri | Enter the metastore URI string. This property is only available when you select Hive or Rest from the Type drop-down list. |
| Catalog implementation | Enter the custom catalog implementation to be used. This property is only available when you select Custom from the Type drop-down list. |
| Catalog properties | Enter additional properties for the catalog. For more information, see [Configuration](https://iceberg.apache.org/docs/latest/configuration/) from the Iceberg documentation. This property is only available when the Register new catalog check box is selected. |

## Usage

| Usage guidance | Description |
| --- | --- |
| Usage rule | This component works standalone in a subJob to register Iceberg catalogs for the whole Spark Structured Streaming Job.  This component, along with the Spark Structured Streaming component Palette it belongs to, appears only when you are creating a Spark Structured Streaming Job. |
| Spark Connection | You need to use the Structured Streaming Configuration tab in the Run view to define the connection to a Spark cluster for the whole Job.  This connection is effective on a per-Job basis. |

# tIcebergCatalog Standard properties

Last updated: 9/30/2026

These properties are used to configure tIcebergCatalog running in
the Standard Job framework.

The Standard
tIcebergCatalog component belongs to the Big Data family.

The component in this framework is available in all Talend
products.

This component is available when you have installed the 8.0.1-R2024-02 Studio Monthly or a
later one provided by Talend. For
more information, check with your administrator.

## Basic settings

| Properties | Description |
| --- | --- |
| Connection | Select from the drop-down list the tIcebergConnection component by which the desired connection is established. |
| Catalog name | Enter the name of the catalog. |
| Type | Select the type of catalog to be created from the drop-down list:  * Hadoop: creates an Iceberg catalog loading tables   from a Hadoop warehouse. * Hive: creates an Iceberg catalog loading tables from   a Hive metastore. * Custom: creates an Iceberg catalog loading tables   from a custom metastore. |
| Warehouse path | Enter the root path to the warehouse in which the catalog is stored. |
| Metastore Uri | Enter the metastore URI string. This property is only available when you select Hive from the Type drop-down list. |
| Client pool size | Set the client pool size. This property is only available when you select Hive from the Type drop-down list. |
| Catalog implementation | Enter the custom catalog implementation to be used. This property is only available when you select Custom from the Type drop-down list. |
| Catalog properties | Enter any extra properties to be used for the catalog. For more information, see [Configuration](https://iceberg.apache.org/docs/latest/configuration/) from the Iceberg documentation. |

## Advanced settings

| Properties | Description |
| --- | --- |
| tStatCatcher Statistics | Select this check box to collect the log data at a component level. |

## Global Variables

| Variables | Description |
| --- | --- |
| ERROR\_MESSAGE | The error message generated by the component when an error occurs. This is an After variable and it returns a string. |

## Usage

| Usage guidance | Description |
| --- | --- |
| Usage rule | This component is generally used with other Iceberg components. |
