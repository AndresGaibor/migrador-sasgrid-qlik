# tSambaClose

Last updated: 9/30/2026

Closes an active Samba connection created by a tSambaConnection
component. This component supports Samba version 2 and Samba version 3.

## tSambaClose Standard properties

These properties are used to configure tSambaClose running in the Standard Job framework.

The Standard
tSambaClose component belongs to the Internet family.

The component in this framework is available in all
subscription-based Talend
products.

Information noteNote: This component is available only when you have installed the 8.0 R2022-02 Talend Studio Monthly
update or a later one delivered by Talend. For
more information, check with your administrator.

## Basic settings

| Properties | Description |
| --- | --- |
| Component List | Select the component that opens the connection you want to close from the list. |

## Advanced settings

| Properties | Description |
| --- | --- |
| tStatCatcher Statistics | Select this checkbox to gather the Job processing metadata at the Job level as well as at each component level. |

## Global Variables

| Variables | Description |
| --- | --- |
| ERROR\_MESSAGE | The error message generated by the component when an error occurs. This is an After variable and it returns a string. |
| NB\_LINE | The number of rows processed. This is an After variable and it returns an integer. |

## Usage

| Usage guidance | Description |
| --- | --- |
