Last updated: 9/30/2026

These properties are used to configure tRedshiftOutput running in the Spark Batch Job framework.

tRedshiftOutput component belongs to the Databases family.

The component in this framework is available in all
subscription-based Talend products

This component is not supported with Spark 4.0.x.

For example, COMPUPDATE that is used to control whether compression encodings are automatically applied during the execution of a Copy.
