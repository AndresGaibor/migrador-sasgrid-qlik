# tThresholdViolationAlert

Last updated: 9/30/2026

Alerts to any threshold violations regarding the thresholds set on indicators in
different quality analyses created in Talend Studio.

tThresholdViolationAlert communicates with the report database that
stores the analysis results and looks for the thresholds that are violated in the column
analyses. You can then use it with other components in a Job, for example
tSendMail, to alert to any threshold violations. You can generate a
ready-to-use Job that uses tThresholdViolationAlert from Talend Studio. For
further information, see [Generating a Job to alert to threshold
violation](https://help.qlik.com/talend/en-US/studio-user-guide/8.0/generating-jobs-from-reports#generating-a-job-to-alert-to-threshold-violation_t).

This component is not shipped with your Talend Studio by
default. You need to install it using the Feature Manager. For more information, see [Installing features using the Feature Manager](/talend/r/en-US/8.0/studio-user-guide/install-features-to-talend-studio).

## tThresholdViolationAlert Standard properties

These properties are used to configure tThresholdViolationAlert running in the Standard Job framework.

The Standard
tThresholdViolationAlert component belongs to the Data Quality family.

This component is available in Talend Data Management Platform, Talend Big Data Platform, Talend Real-Time Big Data Platform, Talend Data Services Platform and in
Talend Data Fabric.
