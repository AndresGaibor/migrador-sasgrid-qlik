# cKafkaCommit

Last updated: 9/30/2026

Triggers commit to [Apache Kafka](http://kafka.apache.org/) message broker.

For more information, see the Apache camel documentation <https://camel.apache.org/components/latest/>.

Information noteNote: This component is available only if you have installed the R2024-10 Talend Studio Monthly
update or a later one delivered by Talend. For
more information, check with your administrator.

## cKafkaCommit Standard properties

These properties are used to configure cKafkaCommit running in
the Standard Job framework.

The Standard
cKafkaCommit component belongs to the Connectivity family.

## Usage

| Usage guidance | Description |
| --- | --- |
| **Usage rule** | cKafkaCommit can be a middle or end component in a Route. It is used to trigger commit manually to [Apache Kafka](http://kafka.apache.org/) message broker if auto commit is disabled in the cKafka component. For more information, see [cKafka](https://help.qlik.com/talend/en-US/mediation-components/8.0/mediation-kafka/ckafka). |
| Limitation | n/a |
