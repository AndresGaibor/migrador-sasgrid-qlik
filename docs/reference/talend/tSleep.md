# tSleep

Last updated: 9/30/2026

Identifies possible bottlenecks using a time break in the Job for testing or
tracking purpose.

tSleep
implements a time off in a Job execution. In production, it can be used for any needed pause
in the Job to feed input flow for example.

## tSleep Standard properties

These properties are used to configure tSleep running in the Standard Job framework.

The Standard
tSleep component belongs to the Orchestration family.

The component in this framework is available in all Talend
products.

## Basic settings

| Properties | Description |
| --- | --- |
| Pause (in second) | Time in second the Job execution is stopped for. |
