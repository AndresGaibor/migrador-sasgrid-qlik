# tIcebergInput properties for Apache Spark Batch

Last updated: 9/30/2026

These properties are used to configure tIcebergInput running in
the Spark Batch Job framework.

The Spark Batch
tIcebergInput component belongs to the Big Data family.

The component in this framework is available in all Talend
products.

This component is available when you have installed the 8.0.1-R2024-04 Studio Monthly or a
later one provided by Talend. For
more information, check with your administrator.

## Basic settings

| Properties | Description |
| --- | --- |
| Schema | Select the type of schema from the drop-down list:  * Built-In: You create and store the schema locally for this component   only. * Repository: You have already created the schema and stored it in the   Repository. You can reuse it in various projects and Job designs.   Information noteImportant: In Dataset-mode Spark Batch Jobs on Databricks, if an Iceberg table contains a Spark VariantType column, define the corresponding column in the component schema as String. The VariantType value is materialized as JSON text. |
| Edit schema | Click Edit schema to make changes to the schema. If you make changes, the schema automatically becomes built-in. |
| Table | Enter the table name from which you want to read data from. |
| Use time travel | Select this check box to read data by specifying:  * a specific branch name with the Read branch   option * a specific tag name with the Read tag option * a specific date and time with the Read datetime   option * a specific snapshot ID with the Read snapshot ID   option |
| Catalog and Schema | To retrieve a dataset from Unity Catalog, specify the following parameters:  * Catalog: enter the name of the catalog to be used. * Schema: enter the name of the schema to be used.   These fields are only available when you select Enable Unity Catalog with Databricks in the Spark Configuration view of your Spark Batch Job.  These properties are only available when you have installed the 8.0.1-R2025-10 Studio Monthly or a later one provided by Talend. For more information, confirm with your administrator. |

## Global Variables

| Variables | Description |
| --- | --- |
| ERROR\_MESSAGE | The error message generated by the component when an error occurs. This is an After variable and it returns a string. |

## Usage

| Usage guidance | Description |
| --- | --- |
| Usage rule | This component is generally used with other Iceberg components. |

# tIcebergInput Standard properties

Last updated: 9/30/2026

These properties are used to configure tIcebergInput running in the Standard Job framework.

The Standard
tIcebergInput component belongs to the Big Data family.

The component in this framework is available in all Talend
products.

This component is available when you have installed the 8.0.1-R2023-10 Studio Monthly or a
later one provided by Talend. For
more information, check with your administrator.

## Basic settings

| Properties | Description |
| --- | --- |
| Connection | Select from the drop-down list the tIcebergConnection component by which the desired connection is established. |
| Schema | Select the type of schema from the drop-down list:  * Built-In: You create and store the schema locally for this component   only. * Repository: You have already created the schema and stored it in the   Repository. You can reuse it in various projects and Job designs. |
| Edit schema | Click Edit schema to make changes to the schema. If you make changes, the schema automatically becomes built-in. |
| Table | Enter the table name from which you want to read data from. |
| Use time travel | Select this check box to read data by specifying:  * a specific date and time with the Read datetime   option * a specific snapshot ID with the Read snapshot ID   option |
| Use custom SQL query | Select this check to read data by specifying a SQL query. |

## Advanced settings

| Properties | Description |
| --- | --- |
| tStatCatcher Statistics | Select this check box to collect the log data at a component level. |

## Global Variables

| Variables | Description |
| --- | --- |
| ERROR\_MESSAGE | The error message generated by the component when an error occurs. This is an After variable and it returns a string. |

## Usage

| Usage guidance | Description |
| --- | --- |
| Usage rule | This component is generally used with other Iceberg components. |
