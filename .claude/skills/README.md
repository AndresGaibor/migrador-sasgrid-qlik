# Skills del equipo

Copias locales de skills globales útiles para este repositorio. Se guardan en `.claude/skills/` para que estén versionadas y disponibles para el equipo.

- `ponytail`: estilo de trabajo minimalista; está activo en este entorno.
- `git-workflow-and-versioning`: prácticas de trabajo y versionado; consultado durante cambios.
- `ponytail-review`: revisión de calidad conectada al cambio.
- `visual-tester`: comprobación visual del frontend; depende de que el entorno tenga disponible `snap-page`.

Las copias no se sincronizan automáticamente con las versiones globales.
